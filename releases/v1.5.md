# RotaryLegio v1.5

Rotary-speaker firmware for the Noise Engineering Legio, with independent horn/drum inertia, stereo Doppler movement, three cabinet voicings, adjustable microphone geometry, balance, and drive.

- No calibration procedure: Pitch control is active from startup.
- Pitch sweeps from fixed Slow at 0 V to the encoder-selected maximum at +5 V.
- Hit and the Fast switch request that same maximum; Brake overrides both.
- Encoder hold toggles bypass in every switch position.
- Source, build target, and firmware filename now consistently use RotaryLegio.

Download **RotaryLegio.bin** below. Flash through STM32 ROM DFU at address `0x08000000`. See the repository README for controls and installation instructions.

The renamed firmware rebuilt successfully and is byte-for-byte identical to the v1.5 image whose six host test suites passed.

Hardware voltage endpoints use provisional fixed ADC values and remain to be verified. Hardware CPU profiling, stack measurement, and sustained-operation checks remain pending.
